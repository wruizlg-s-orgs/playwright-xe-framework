# Playwright QA Automation Framework

## Tech Stack

- Playwright
- TypeScript
- REST API Testing
- GitHub Actions
- Node.js

## Features

- API testing
- CRUD validation
- Authentication fixture
- Service layer pattern
- Test data factories
- CI execution

## Running tests

Install dependencies:

npm install

Run all tests:

npm test

Run API tests:

npx playwright test --project=api

Type validation:

npm run test:typecheck
